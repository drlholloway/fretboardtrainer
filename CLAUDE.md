# Fretboard Trainer

Flutter monorepo (pub workspace). Pure-Dart music logic lives in
`packages/fretboard_theory` and must stay free of Flutter; the app in
`apps/fretboard_trainer` only renders and stores. Read PLAN.md first.

- `just test` runs everything; `just analyze` before finishing a change.
- Strings are indexed from the lowest-pitched string (0). Fret 0 is open.
- Chords are named from their sounding pitches (`identifyChord`), never from
  a shape label. Add new shapes as offset templates in `ChordLibrary`.
- Lessons are generated by `Curriculum`; ids are stable and stored in
  progress, so do not rename them casually.
- Screens are rendered to `docs/screenshots` by `just screenshots` (golden
  tests with the macOS Arial fonts); regenerate after UI changes.
